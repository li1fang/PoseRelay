# PoseRelay 角色包 / Character package

解压整个 ZIP。安装了 Python 3 的 Windows 双击打开 Start-Windows.cmd。macOS 或 Linux 在解压目录运行 `python3 start.py`。保持启动窗口打开。

Unzip the whole archive. With Python 3 installed, open Start-Windows.cmd on Windows or run `python3 start.py` in the extracted directory on macOS or Linux. Keep the launcher running while playing.

在角色正面点击「试听台词」，然后点击「左看」或「右看」。可用的转头会沿用定稿中的播放速度和口型。回程在台词结束后操作。

At the front pose, start the sample line, then choose a direction. Routes with a mouth track can play through speech. Wait for the line to finish before taking a silent return route.

`review.json` records the approved version. `manifest.json` binds assets, transition rates and the sample voice. `SHA256SUMS` lists the packaged files.

中文版和 English 可在播放器右上角切换。
Use the language link at the top of the player to switch between Chinese and English.
